Фича: умная шторка + карта курса
1. Умная шторка (tree-drawer)
Текущее состояние
renderCourseTree() в renderers.js:415 — рендерит все этапы и все темы подряд
Все задания всех тем видны сразу
Новое поведение
Шторка показывает:

Текущий этап — все темы с заданиями (как сейчас, но только для текущего stage)
Следующие 3 темы из другого этапа — свёрнуты, серого цвета, клик недоступен («заблокированы»)
Темы за пределами — не показываются вообще
«Эффект горизонта»: по мере прохождения разблокируются следующие темы.

Реализация:

В renderCourseTree() добавить логику фильтрации:
currentStageTopics — показываем полностью
nextStageTopics.slice(0, 3) — показываем как ghost-темы без списка заданий
Ghost-тема: CSS-класс tree-topic--locked, opacity, cursor: default, замок иконка
2. Карта курса (course-map)
Концепция
Две версии: ученик (упрощённая) и учитель (полная)
Standalone HTML: dev/course-map.html (или внутри приложения как отдельный экран)
Canvas-подход: SVG или позиционированные div на абсолютном холсте
Связи: линейные (порядок в stages.js) + кросс-ссылки (задаются в stages.js или отдельном файле)
Структура данных для связей
В content/stages.js добавить к каждой теме links:

js

{
  id: 'l1_nested_structures',
  links: ['l1_dicts', 'l1_lists']  // ← кросс-ссылки
}
Визуал
Узлы: карточки тем (название, прогресс ученика)
Рёбра: линейные (→ next topic) серые, кросс-ссылки (↔) пунктиром другого цвета
Состояния узла: done (зелёный), current (акцент), locked (серый)
Drag/pan: простой translateX/Y через mouse events, без либ
Zoom: wheel event + CSS scale
Ученик видит:
Пройденные темы (зелёные)
Текущая (подсвечена)
Следующие N тем (видны, но серые)
Остальные — скрыты туманом (blur/opacity)
Учитель видит (teacher-mode):
Весь граф полностью
Прогресс конкретного ученика (если передать данные через query param или localStorage)
Кросс-ссылки отмечены
Порядок реализации
Сначала: умная шторка (проще, меньше риска) — renderers.js + styles.css
Потом: схема связей в stages.js + canvas-карта в dev/course-map.html

Карта:
