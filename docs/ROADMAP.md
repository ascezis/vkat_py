# Дорожная карта проекта (ROADMAP)

Документ фиксирует стратегические границы версий, состав задач для закрытия линейки **v2.0 (v2.x)** и будущий переход к мажору **v3.0**.

---

## 1. Текущий статус (Рубеж Октябрь 2026)

* **Базовая версия:** `v2.2.0` (ветка `main`).
* **Что уже сделано и зацементировано:**
  - Полностью автономный офлайн-рантайм CPython (Pyodide WebAssembly, Zero-Build, без npm/Webpack).
  - Мультипрофильная система хранения `VkatStorage` (аппаратная изоляция вкладок, SHA-256 PIN-коды, экспорт/импорт профилей, гостевой вход).
  - Декомпозиция ядра на независимые модули (`app.js`, `profiles.js`, `renderers.js`, `checkers.js`).
  - Строгая монохромная дизайн-система (`docs/design-system.md`) и SVG-глифы тем.
  - Автоматизированный конвейер CI/CD (162 автоматических теста в `dev/`, автодеплой на Pages и автосборка офлайн-ZIP).
  - Спецификация авторинга тем (`docs/ADDING-TOPICS.md`) и регламент сопровождения (`CONTRIBUTING.md`).

---

## 2. Стратегия версионирования: 2.0 vs 3.0

Мы сознательно разделяем продукт на два фундаментальных этапа:

```
┌────────────────────────────────────────────────────────────────────────┐
│  v2.x — «Железобетонный Standalone-тренажёр»                           │
│  Цель: идеальный, замкнутый, автономный офлайн-продукт для учеников    │
│  ──────────────────────────────────────────────────────────────────    │
│  • Полировка дизайн-системы (проверка 1366×768, контраст, хоткеи)      │
│  • Модуль встроенного справочника (быстрая шпаргалка по синтаксису)    │
│  • 8 новых тем основного курса (полный цикл обучения Python до ООП)    │
│  • 100% покрытие эталонами и негативными тестами                       │
│  • Сборка релизного золотого пакета v2.0 Final                         │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ Полная стабилизация
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│  v3.0 — «Экосистема CONNECT & Фоновый рантайм»                         │
│  Цель: переход от локального тренажёра к сетевой среде класса          │
│  ──────────────────────────────────────────────────────────────────    │
│  1. Web Worker Sandbox («Антифриз» — исполнение Pyodide в фоне)        │
│  2. Редизайн интерфейса под экосистему CONNECT                         │
│  3. CONNECT-PROTOCOL (телеметрия, outbox, локальный сервер учителя)    │
│  4. Экспериментальные холсты (Canvas-визуализаторы, мини-игры)         │
└────────────────────────────────────────────────────────────────────────┘
```

> ⚠️ **Архитектурный закон v2.x:** В версию 2.0 **НЕ** добавляются сетевые протоколы, фоновые воркеры и холсты. Линейка 2.0 полируется как бескомпромиссный офлайн-монолит.

## 3. Скоуп задач для закрытия v2.0 Final

Закрытие второй версии состоит строго из трёх блоков:

### Блок А. Модуль встроенного справочника (Cheat Sheet)
* **Назначение:** Быстрый доступ к синтаксису и примерам прямо во время решения задач, не выходя из тренажёра и не сбивая фокус редактора.
* **Архитектура:**
  - Модуль интерфейса: `app/cheatsheet.js` (выезжающая шторка-drawer или модалка по нажатию `[ ? Справочник ]` в шапке или клавише `F1` / `Ctrl+/`).
  - Статический контент: `content/cheatsheet.js` (ёмкие выжимки по разделам).
* **Разделы шпаргалки:**
  1. *Строки и срезы:* `s[start:stop:step]`, `.split()`, `.join()`, `.strip()`, `.replace()`, `.find()`, f-строки.
  2. *Списки и кортежи:* `.append()`, `.pop()`, `.sort()`, `len()`, срезы, распаковка `a, b = tup`.
  3. *Словари и множества:* `.get()`, `.keys()`, `.values()`, `.items()`, `.add()`, операторы `in` / `not in`.
  4. *Условия и циклы:* `if/elif/else`, `for in range()`, `while`, `break`/`continue`, `and/or/not`.
  5. *Функции:* `def f(x, y=0):`, `return`, `*args/**kwargs`.
  6. *Расшифровка ошибок:* скорая помощь при `SyntaxError`, `IndentationError`, `IndexError`, `KeyError`, `TypeError`.

### Блок В. Финальная дизайн-полировка (Design Polish)
* **Адаптивность под школьные ноутбуки:** Проверка лейаута на разрешениях 1366×768 и 1280×720 (гарантия отсутствия паразитных вертикальных скроллов окна при открытом редакторе).
* **Монохромная калибровка:** Проверка соответствия всех элементов токенам из [`docs/design-system.md`](file:///c:/Users/azis/Desktop/vkat_py-main/docs/design-system.md). Никаких цветных акцентов, идеальный контраст инверсии.
* **Доступность и хоткеи:**
  - `Ctrl+Enter` — запуск и проверка кода;
  - `Ctrl+/` / `F1` — открытие/закрытие справочника;
  - `Esc` — закрытие любых модальных окон (PIN, профили, справочник).
* **Аудит мобильных/планшетных экранов:** базовый читаемый просмотр теории и квизов.

## 4. Критерии готовности v2.0 Final (Definition of Done)

Релиз v2.0 объявляется **завершённым**, когда:
1. [ ] Модуль справочника внедрён и наполнен проверенным материалом.
2. [ ] Все 8 тем добавлены в `content/core/` и зарегистрированы в реестре этапов.
3. [ ] Скрипт `node dev/run_js_validation.js` проходит без ошибок.
4. [ ] Скрипт `python dev/run_tests.py` успешно прогоняет эталоны для всех 8 тем (0 ошибок).
5. [ ] Страница `dev/selftest.html` в браузере горит полностью зелёным.
6. [ ] Сформирован релизный тег `v2.0.0` (или `v2.2.0`), опубликован GitHub Release и проверен автономный ZIP-архив на чистой машине без интернета.

## 5. Перспектива: Мажор v3.0

После закрытия v2.0 проект переходит к ветке `v3.x`:

1. **v3.0.0 — Web Worker Sandbox («Антифриз»):**
   - Перенос Pyodide в фоновый Web Worker (`app/worker.js`).
   - Изоляция UI-потока: браузер никогда не замерзает при `while True:`.
   - Жёсткий аппаратный таймаут (3 секунды) с автоматическим прерыванием зациклившегося воркера.
2. **v3.1.0 — Редизайн под экосистему CONNECT:**
   - Новый UI-каркас с поддержкой классов, статуса подключения и режима контрольных работ.
3. **v3.2.0 — Реализация CONNECT-PROTOCOL:**
   - Модуль `app/connect.js` (outbox-очередь в `localStorage`, тихий `fetch`).
   - Сбор расширенной телеметрии (`attempts`, `errorsEncountered`, итоговый код).
   - Эталонный локальный сервер преподавателя `teacher.py` (стандартная библиотека Python, без зависимостей).
4. **v3.3.0 — Экспериментальные холсты:**
   - Подключение визуализатора `<canvas>` для мини-пет-проектов (текстовый рогалик, шахматная доска, симуляции).
