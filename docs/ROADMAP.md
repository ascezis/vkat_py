# Дорожная карта проекта (ROADMAP)

Документ фиксирует стратегические границы версий, состав задач для закрытия линейки **v2.0 (v2.x)** и будущий переход к мажору **v3.0**.

---

## 1. Текущий статус (Рубеж Октябрь 2026)

* **Базовая версия:** `v2.3.1` (релиз v2.0 Final / v2.3.1).
* **Что уже сделано и зацементировано:**
  - Полностью автономный офлайн-рантайм CPython (Pyodide WebAssembly, Zero-Build, без npm/Webpack).
  - Мультипрофильная система хранения `VkatStorage` (аппаратная изоляция вкладок, SHA-256 PIN-коды, экспорт/импорт профилей, гостевой вход).
  - Декомпозиция ядра на независимые модули (`app.js`, `profiles.js`, `renderers.js`, `checkers.js`, `checker.js`, `code-hints.js`, `autocomplete.js`, `highlighter.js`, `glyphs.js`).
  - Строгая монохромная дизайн-система (`docs/design-system.md`) и SVG-глифы тем.
  - Встроенная контекстная база синтаксиса `CodeHints` (`content/cheatsheet.js` + `app/code-hints.js`) с подсветкой синтаксиса в поповерах без потери фокуса редактора.
  - 15 учебных тем и **211 учебных элементов** (26 в модуле «Начало» + 185 в модуле «Основной курс»).
  - 100% тестовое покрытие: 312 проверок структуры в `dev/run_js_validation.js`, 204 теста эталонов и негативных кейсов в `python dev/run_tests.py`, браузерный раннер `dev/selftest.html`.
  - Автоматизированный конвейер CI/CD (GitHub Actions CI на ubuntu-latest, автодеплой на Pages и автосборка офлайн-ZIP).
  - Спецификация авторинга тем (`docs/ADDING-TOPICS.md`) и регламент сопровождения (`CONTRIBUTING.md`).

## 2. Стратегия версионирования: 2.0 vs 3.0

Мы сознательно разделяем продукт на два фундаментальных этапа:

```
┌────────────────────────────────────────────────────────────────────────┐
│  v2.x — «Железобетонный Standalone-тренажёр»                           │
│  Цель: идеальный, замкнутый, автономный офлайн-продукт для учеников    │
│  ──────────────────────────────────────────────────────────────────    │
│  • Полировка дизайн-системы (проверка 1366×768, контраст, хоткеи)      │
│  • Контекстные подсказки CodeHints по синтаксису прямо в теории        │
│  • 9 тем основного курса (полный цикл обучения Python до ООП)          │
│  • 100% покрытие эталонами и негативными тестами (204 py + 312 js)     │
│  • Сборка релизного золотого пакета v2.0 Final                         │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ Полная стабилизация
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│  v3.0 — «Экосистема CONNECT, Умная шторка & Фоновый рантайм»           │
│  Цель: переход от локального тренажёра к сетевой среде класса          │
│  ──────────────────────────────────────────────────────────────────    │
│  1. Web Worker Sandbox («Антифриз» — исполнение Pyodide в фоне)        │
│  2. Умная шторка («эффект горизонта») и Canvas-карта тем курса         │
│  3. Редизайн интерфейса под экосистему CONNECT                         │
│  4. CONNECT-PROTOCOL (телеметрия, outbox, локальный сервер учителя)    │
│  5. Экспериментальные холсты (Canvas-визуализаторы, мини-игры)         │
└────────────────────────────────────────────────────────────────────────┘
```

> ⚠️ **Архитектурный закон v2.x:** В версию 2.0 **НЕ** добавляются сетевые протоколы, фоновые воркеры и холсты. Линейка 2.0 полируется как бескомпромиссный офлайн-монолит.

## 3. Скоуп задач для закрытия v2.0 Final

Закрытие второй версии состоит строго из трёх блоков:

### Блок А. Контекстная база синтаксиса и подсказки (Code Hints)
* **Назначение:** Мгновенный доступ к синтаксису, сигнатурам методов и частым ошибкам прямо при изучении теории, не сбивая фокус редактора.
* **Архитектура:**
  - Модуль интерфейса: `app/code-hints.js` (интерактивные токены в блоках теории с подсветкой `PythonHighlighter` и плавающим поповером `.hint-popover`).
  - Статический контент: `content/cheatsheet.js` (база конструкций Python: синтаксис, краткое описание, примеры кода, частые ловушки, рекомендации PEP 8).
* **Покрытие базы синтаксиса:**
  1. *Строки и срезы:* `s[start:stop:step]`, `.split()`, `.join()`, `.strip()`, `.replace()`, `.find()`, f-строки.
  2. *Списки и кортежи:* `.append()`, `.pop()`, `.sort()`, `len()`, срезы, распаковка `a, b = tup`.
  3. *Словари и множества:* `.get()`, `.keys()`, `.values()`, `.items()`, `.add()`, операторы `in` / `not in`.
  4. *Условия и циклы:* `if/elif/else`, `for in range()`, `while`, `break`/`continue`, `and/or/not`.
  5. *Функции:* `def f(x, y=0):`, `return`, `*args/**kwargs`.
  6. *Расшифровка ошибок:* скорая помощь при `SyntaxError`, `IndentationError`, `IndexError`, `KeyError`, `TypeError`.

### Блок В. Финальная дизайн-полировка (Design Polish)
* **Адаптивность под школьные ноутбуки:** Проверка лейаута на разрешениях 1366×768 и 1280×720 (гарантия отсутствия паразитных вертикальных скроллов окна благодаря `body { overflow: hidden; }` и независимым скролл-панелям).
* **Монохромная калибровка:** Полное соответствие дизайн-системе (`docs/design-system.md`). Отсутствие цветного мусора, читаемый контраст и 6px кастомные полосы прокрутки.
* **Доступность и хоткеи:**
  - `Ctrl+Enter` — запуск и проверка кода в редакторе и в поле ввода предсказаний;
  - `Enter` — отправка ответа в поле `predict`;
  - `Esc` — закрытие поповера подсказок, шторки тем и модального окна PIN-кода.
* **Автономный запуск:**
  - Скрипт `run.bat` для быстрого старта на Windows через локальный сервер Python 3.12/py (или прямое открытие в браузере при отсутствии Python).

## 5. Перспектива: Мажор v3.0

После закрытия v2.0 проект переходит к ветке `v3.x`:

1. **v3.0.0 — Web Worker Sandbox («Антифриз») & Умная шторка:**
   - Перенос Pyodide в фоновый Web Worker (`app/worker.js`).
   - Изоляция UI-потока: браузер никогда не замерзает при `while True:`.
   - Жёсткий аппаратный таймаут (3 секунды) с автоматическим прерыванием зациклившегося воркера.
   - Умная шторка (tree-drawer): «эффект горизонта» с замками на будущих темах.
   - Интерактивная карта тем курса (Canvas / SVG граф связей между темами).
2. **v3.1.0 — Редизайн под экосистему CONNECT:**
   - Новый UI-каркас с поддержкой классов, статуса подключения и режима контрольных работ.
3. **v3.2.0 — Реализация CONNECT-PROTOCOL:**
   - Модуль `app/connect.js` (outbox-очередь в `localStorage`, тихий `fetch`).
   - Сбор расширенной телеметрии (`attempts`, `errorsEncountered`, итоговый код).
   - Эталонный локальный сервер преподавателя `teacher.py` (стандартная библиотека Python, без зависимостей).
4. **v3.3.0 — Экспериментальные холсты:**
   - Подключение визуализатора `<canvas>` для мини-пет-проектов (текстовый рогалик, шахматная доска, симуляции).
