# Дорожная карта проекта (ROADMAP)

Документ фиксирует эры версий, фактический статус и следующие мажоры.
Версия — единый источник истины: `app/version.js` (SemVer, правится при релизах).

### Эра 4.x — «Зеркало препода» (следующий мажор)

Появление второй роли в продукте: реверс-сервис внутри тренажёра.

- **4.0.0 — Teacher Lens**: препод открывает `/app/` под своей сессией консоли и видит в
  интерфейсе урока блок «для препода»: эталоны (`dev/selftest/`), скрытые тесты, все
  подсказки, карта застреваний класса по текущему заданию. Endpoint `/api/teacher/item/<id>`
  в connect-console, эталоны отдаются только за учительской cookie
  (файлы selftest закрыты в PRIVATE_DIRS — 787f93e).
- **4.x** — конспект-репетиция пары (разметка плана по дереву курса), режим задания
  (назначить тему/контрольную классу).

Серверная половина экосистемы живёт в отдельном приватном репо
[`ascezis/connect-console`](https://github.com/ascezis/connect-console) со своей
нумерацией (`CONNECT_VERSION`, сейчас 0.2.0): приём телеметрии, раздача тренажёра в LAN,
живой дашборд, вид «подготовка пары» (`/api/prep`), безопасность (PIN-cookie, lockout,
rate-limit, валидация payload, приватные каталоги).

## 3. Правила версионирования

- Источник истины — `app/version.js`; валидатор требует строгий SemVer (`X.Y.Z`, без суффиксов).
- **MAJOR** — смена эры/архитектуры (3.x = экосистема, 4.x = вторая роль).
- **MINOR** — новые темы, этапы, модули (волны функционала).
- **PATCH** — фиксы и полировка.
- Коммиты по Conventional Commits (`feat!:`/`BREAKING CHANGE:` → MAJOR), теги `#patch/#minor/#major`.
- Бамп происходит в коммите релиза, а не в фича-коммитах.
