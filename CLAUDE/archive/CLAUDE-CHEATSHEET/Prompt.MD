# ИНСТРУКЦИЯ ДЛЯ CLAUDE: СОСТАВЛЕНИЕ КОНТЕНТА СПРАВОЧНИКА (content/cheatsheet.js)

## 1. Роль и контекст
Ты выступаешь в роли ведущего методиста и автора контента по Python для образовательного тренажёра **vkat.py**.
Твоя задача — составить **эталонный файл контента `content/cheatsheet.js`** со всеми 7 разделами по спецификации [`CHEATSHEET-SPEC.md`](CHEATSHEET-SPEC.md).

> ⚠️ **Важно:** Тебе **НЕ нужно** писать HTML/CSS и верстать шторку, и **НЕ нужно** трогать существующие файлы тем! Движок интерфейса, шторку и тесты мы подключим сами. От тебя требуется **только чистый, качественный контентный файл `content/cheatsheet.js`**.

## 2. Требования к контенту

Файл `content/cheatsheet.js` экспортирует в глобальную область массив:
```javascript
window.CHEATSHEET_SECTIONS = [
  /* 7 разделов */
];
```

Каждая карточка (`item`) обязана содержать:
1. `id`: строковый уникальный ID (snake_case), например `"str_slice"`, `"dict_get"`.
2. `title`: ёмкое название метода или концепции (на русском).
3. `syntax`: чистый синтаксис/шаблон (например: `d.get(key, default=None)`).
4. `desc`: краткое объяснение (1–2 фразы, живой понятный русский язык без канцелярита).
5. `code`: рабочий мини-пример на Python с комментариями `# результат`.
6. `pitfall`: **пограничный случай / грабли / частая ошибка** (что крашит код или делает не то).
7. `style`: **рекомендация PEP 8 и идиоматичного кода** (как принято писать в реальной разработке).
8. `topics`: массив строковых ID тем курса (брать строго из файла [`TOPIC-IDS.md`](TOPIC-IDS.md)).
9. `tags`: 5–10 ключевых слов (на русском и английском) для мгновенного поиска.

## 3. Обязательный состав разделов (7 секций)

Составь исчерпывающий набор карточек для всех 7 разделов:

### 1. `basics` («Базовый синтаксис и типы»)
* Связь: `topics: ["variables"]`.
* Карточки:
  - Типы данных: `int`, `float`, `str`, `bool` (особенности приведения `int("42")`, `bool(0)` vs `bool("")`).
  - Ввод и вывод: `print(*args, sep=" ", end="\n")`, `input(prompt)`.
  - Деление: обычное `/` (всегда float!), целочисленное `//`, остаток `%`.
  - f-строки: форматирование `f"{name}: {score + 10}"`.
  - Порядок и приоритет операций.

### 2. `control` («Условия и циклы»)
* Связь: `topics: ["conditions", "loops", "l1_loops_adv"]`.
* Карточки:
  - Ветвления: `if / elif / else` (ловушка с несколькими независимыми `if` вместо `elif`).
  - Логика: операторы `and`, `or`, `not` (ленивые вычисления, приоритет `not` > `and` > `or`).
  - Цикл `for` по итерируемым объектам.
  - Генератор диапазонов `range(start, stop, step)` (включая отрицательный шаг для обратного счёта).
  - Цикл `while` (защита от бесконечного цикла, обязательное изменение счетчика).
  - Управление циклом: `break` (выход) и `continue` (пропуск итерации).

### 3. `strings` («Строки и срезы»)
* Связь: `topics: ["strings", "l1_strings"]`.
* Карточки:
  - Индексация и срезы: `s[start:stop:step]`, отрицательные индексы `s[-1]`, разворот `s[::-1]`.
  - Метод `.split(sep=None)`: разбивка строки на список слов.
  - Метод `sep.join(iterable)`: склейка списка строк через разделитель.
  - Очистка от пробелов: `.strip()`, `.lstrip()`, `.rstrip()`.
  - Поиск и замена: `.find()` (вернёт -1, а не ошибку), `.replace(old, new)`.
  - Регистр символов: `.lower()`, `.upper()`, `.capitalize()`.
  - Неизменяемость строк (строку нельзя изменить через `s[0] = 'X'`).

### 4. `lists_tuples` («Списки и кортежи»)
* Связь: `topics: ["lists-dicts", "l1_lists", "l1_tuples"]`.
* Карточки:
  - Создание списка и кортежа: `[]`, `()`, одноэлементный кортеж `(x,)`.
  - Добавление элементов: `.append(item)`, объединение `+`.
  - Удаление элементов: `.pop(i)`, `del a[i]`.
  - Сортировка: метод `.sort()` (изменяет на месте! возвращает None) vs функция `sorted(lst)` (возвращает новый).
  - Поиск и подсчёт: `.index(x)`, `.count(x)`, оператор `x in lst`.
  - Срезы списков (создание поверхностной копии `lst[:]`).
  - Распаковка кортежей: `a, b = tup`, множественное присваивание `x, y = y, x`.
  - Неизменяемость `tuple`: защита данных, кортеж как ключ словаря.

### 5. `dicts_sets` («Словари и множества»)
* Связь: `topics: ["lists-dicts", "l1_dicts", "l1_nested_structures"]`.
* Карточки:
  - Создание словаря и чтение по ключу: `d[key]`.
  - Безопасное чтение: `.get(key, default=None)` (ловушка: прямое чтение бросает `KeyError`).
  - Перебор словаря: `.keys()`, `.values()`, `.items()` (распаковка в цикле `for k, v in d.items():`).
  - Проверка наличия ключа: `key in d` (быстрый O(1) поиск).
  - Множества `set()`: уникальные элементы, метод `.add()`, проверка `x in s`.
  - Вложенные структуры: словарь списков, список словарей, глубокий доступ `data[0]["name"]`.

### 6. `functions` («Функции»)
* Связь: `topics: ["functions", "l1_functions"]`.
* Карточки:
  - Определение функции: `def name(param1, param2=default):`.
  - Оператор `return` vs `print()` (ловушка: забытый `return` неявно возвращает `None`).
  - Позиционные и именованные аргументы: вызов `f(10, step=2)`.
  - Области видимости: локальные переменные, глобальные переменные, чтение vs запись (`global`).
  - Ловушка изменяемых значений по умолчанию: `def add(x, lst=[])` (опасность сохранения состояния между вызовами!).
  - Базовые встроенные функции: `len()`, `sum()`, `min()`, `max()`, `abs()`, `round()`.

### 7. `errors` («Скорая помощь при ошибках»)
* Связь: `topics: []`.
* Карточки:
  - `SyntaxError`: забытое двоеточие `:`, незакрытая кавычка или скобка.
  - `IndentationError`: сбитый отступ (смесь табов и пробелов, лишний/недостающий отступ).
  - `NameError`: опечатка в имени переменной/функции или вызов до объявления.
  - `IndexError`: попытка обратиться по несуществующему индексу списка/строки.
  - `KeyError`: попытка прочитать несуществующий ключ словаря без `.get()`.
  - `TypeError`: сложение несовместимых типов (`"5" + 2`), вызов не-функции, работа с `None`.
  - `ZeroDivisionError`: деление на ноль (`/ 0` или `% 0`).
