## 1. Паспорт проекта и Hard Constraints

* **Что это:** Автономный офлайн-тренажёр по Python для учеников школы программирования.
* **Стек:** Vanilla HTML5 + CSS3 + ES6+ JavaScript. Никаких сборщиков (Zero-Build: нет npm, Webpack, Vite, React).
* **Рантайм Python:** Pyodide (CPython 3.12 WebAssembly), встроен локально в `assets/pyodide/`. Работает на 100% без интернета.
* **Строгий монохром:** Интерфейс оформлен в эстетике терминала. Цвета не используются для акцентов (только инверсия и толщина линий 1px).

## 2. Что УЖЕ реализовано (НЕ дублировать в новых темах!)

### Этап 1: «Начало» (`content/start/`)
Базовые 6 тем закрывают начальный синтаксис:
* `01-variables.js` (`variables`) — переменные, числа, строки, `print()`.
* `02-conditions.js` (`conditions`) — ветвления `if / elif / else`.
* `03-loops.js` (`loops`) — базовый цикл `for in range()`.
* `04-functions.js` (`functions`) — базовые функции без усложнений.
* `05-lists-dicts.js` (`lists-dicts`) — начальное знакомство со списками и словарями.
* `06-strings.js` (`strings`) — базовые операции со строками.

### Этап 2: «Основной курс» (`content/core/` — уже готово):
* **`01-functions.js` (`l1_functions`):** Функции (def, параметры, return, default, локальные переменные).
* **`02-dicts.js` (`l1_dicts`):** Словари (пары ключ-значение, .get(), .keys(), .values(), .items(), частоты).
* **`03-lists.js` (`l1_lists`):** Списки (срезы [start:stop:step], comprehension, enumerate, zip, матрицы).
* **`04-tuples.js` (`l1_tuples`):** Кортежи (неизменяемость, распаковка, возврат нескольких значений).
* **`05-strings-adv.js` (`l1_strings`):** Строки (методы .split(), .join(), .strip(), .replace(), .find(), f-строки).
* **`06-loops-adv.js` (`l1_loops_adv`):** Циклы (while, break/continue, вложенные циклы, range с шагом).

## 4. Эталонный состав темы (15–20 элементов)

Каждая тема содержит сбалансированный набор элементов на 45–60 минут прохождения:
* **Теория (`type: "theory"`):** 4–5 страниц, разбитых на блоки `p`, `code`, `note`, `table`.
* **Квизы (`type: "quiz"`):** 2–3 вопроса на проверку концепций с 4 вариантами ответа и `explain`.
* **Предсказания (`type: "predict"`):** 2–3 фрагмента кода с вводом ожидаемого вывода программы.
* **Поиск ошибок (`type: "code"`, `kind: "fix"`):** 1–2 задачи с `kind: "fix"` (tier обычно `"warmup"` или `"main"`), предзаполненным кодом с ошибкой и описанием в `explanation`.
* **Основные задачи (`type: "code"`, `tier: "main"`):** 4–5 практических задач с `tests[]`, 3-уровневыми `hints[]` и AST-требованиями.
* **Задачи со звёздочкой (`type: "code"`, `tier: "star"`, `optional: true`):** 1–2 необязательные усложнённые задачи.

## 5. Ограничения Pyodide и детерминированность тестов

1. **Никакого `input()` в задачах:** Все входные данные передаются как аргументы функций, а результат проверяется через `returns:` или `stdout:`.
2. **Детерминированность `random`:**
   - Либо фиксировать сид в вызове теста: `random.seed(42)`.
   - Либо проверять инварианты результата: `len(res) == 5`, `res in [1, 2, 3]`.
3. **Исключения из тестов:**
   - Не использовать чтение/запись файлов `open()` в тестах.
   - Не использовать недетерминированный `datetime.now()` (вместо него тестировать парсинг фиксированных строк через `strptime` и смещения `timedelta`).
4. **Поддерживаемые флаги AST-анализатора (`astRequirements`):**
   - `require_def: true` — наличие `def`
   - `require_return: true` — наличие `return`
   - `require_if: true` — наличие `if`
   - `require_for: true` — наличие цикла `for`
   - `require_while: true` — наличие цикла `while`
   - `require_loop: true` — наличие любого цикла (`for` или `while`)
   - `require_try: true` — наличие блока `try / except`
   - `require_raise: true` — наличие оператора `raise`
   - `require_calls: ["func_name"]` — обязательный вызов функции
   - `forbid_calls: ["eval", "exec"]` — запрет вызова функций
   - `forbid_methods: ["sort"]` — запрет вызова методов

## 6. Алгоритм подключения новой темы (Чек-лист)

После написания файла темы `content/core/l1-XX-<name>.js`:

1. **Регистрация в реестре этапов:**  
   Открыть `content/stages.js` и добавить ID темы в массив `topics` этапа `core`.
2. **Подключение скрипта в HTML:**  
   Открыть `index.html` и добавить тег перед `app/app.js`:  
   `<script src="content/core/l1-XX-<name>.js"></script>`
3. **Локальная верификация:**  
   Запустить в терминале:
   ```bash
   node dev/run_js_validation.js
   python dev/run_tests.py
   ```
   Оба раннера должны выдать строго **0 ошибок**.
