# Спецификация модуля: Встроенный справочник (Cheat Sheet)

Документ регламентирует архитектуру, схему данных, правила интеграции и UX-модель модуля **«Встроенный справочник по Python»** для тренажёра `вкат.py` в соответствии с [Issue #3](https://github.com/ascezis/vkat_py/issues/3) и [ROADMAP.md (Блок А)](ROADMAP.md).

---

## 1. Концепция и архитектурные принципы

1. **Автономность и Zero-Build**: Справочник работает полностью офлайн в браузере, без сетевых запросов и сторонних библиотек.
2. **Слабая связанность (Loose Coupling)**:
   - **Существующие файлы тем (`content/start/*.js`, `content/core/*.js`) не изменяются ни на один байт.**
   - Спецификация авторинга заданий ([ADDING-TOPICS.md](ADDING-TOPICS.md)) остаётся без изменений.
   - Связь между справочником и темами курса является **односторонней**: только карточки справочника знают строковые ID тем (`topics: ['l1_dicts', 'lists-dicts']`), к которым они относятся.
3. **Неразрушающий UX (Non-destructive)**:
   - Открытие справочника **не сбрасывает** текущее задание, черновик кода в редакторе или состояние выполнения.
   - При закрытии справочника клавишей `Esc` фокус ввода гарантированно возвращается в редактор кода (`#editor-textarea`).
4. **Практическая польза ученика (Cheat Sheet, а не учебник)**:
   - Ёмкие, быстро считываемые карточки (синтаксис + мини-пример).
   - Обязательный разбор **пограничных случаев и ловушек (Pitfalls)**.
   - Рекомендации по чистоте и стилю оформления кода (**PEP 8**).

### 2.1. Форм-фактор: Правая выезжающая шторка (`.cheatsheet-drawer`)
* **Позиционирование**: фиксированная шторка справа (`position: fixed; right: -480px; width: 460px; max-width: 92vw; height: 100vh; z-index: 2000`).
* **Анимация**: плавный выезд `right: 0` (`transition: right 0.28s cubic-bezier(0.16, 1, 0.3, 1)`), зеркально левой шторке дерева тем (`.tree-drawer`).
* **Монохромная эстетика**: 0px border-radius, границы `1px solid var(--border-strong)`, фон `var(--bg-panel)`, кастомный 6px ретро-скроллбар.

### 2.2. Горячие клавиши и триггеры
* `F1` или `Ctrl+/` — открыть/закрыть справочник (toggle).
* `Esc` — закрыть справочник и вернуть фокус в редактор.
* Кнопка в шапке `#btn-cheatsheet-toggle` (`[ ? справочник ]`) — открытие кликом.
* Клик по затемняющему оверлею (`.cheatsheet-overlay`) или кнопке-крестику `✕` — закрытие.

### 2.3. Контекстная фильтрация по текущей теме (`openForTopic`)
Когда ученик находится внутри конкретного занятия:
1. Вызов `Cheatsheet.openForTopic(state.currentTopicId)` автоматически:
   - Включает фильтр по текущей теме.
   - Отображает плашку над списком: `Тема урока: <Название темы> · [показать всё]`.
   - Выводит первыми карточки, у которых `topics` содержит `currentTopicId`.
2. Клик на `[показать всё]` или выбор другого таба сбрасывает контекстный фильтр.

### 2.4. Живой поиск (Instant Filter)
* Поле ввода с автофокусом при открытии.
* Регистронезависимый мгновенный поиск без регулярных выражений:
  - по `title` (название);
  - по `syntax` (сигнатура/шаблон);
  - по `desc` (описание);
  - по `code` (пример);
  - по `tags` (ключевые слова на русском и английском: *«срез», «длина», «len», «append»*);
  - по `pitfall` (поиск по типам ошибок: *«KeyError», «IndexError», «NoneType»*).
* Кнопка быстрой очистки поля поиска.

## 3. Спецификация схемы данных (`content/cheatsheet.js`)

Файл `content/cheatsheet.js` экспортирует в глобальную область видимости структуру `window.CHEATSHEET_SECTIONS`:

```javascript
window.CHEATSHEET_SECTIONS = [
  {
    id: "strings",                 // Уникальный строковый ID категории
    title: "Строки и срезы",       // Название для табов и заголовков
    items: [
      {
        id: "str_slice",           // Уникальный строковый ID карточки
        title: "Срезы строк",
        syntax: "s[start:stop:step]",
        desc: "Извлечение подстроки. Индексы отсчитываются с 0. Все параметры опциональны.",
        code: "s = \"Python\"\ns[0:2]    # \"Py\"\ns[2:]     # \"thon\"\ns[::-1]   # \"nohtyP\" (разворот строки)",
        pitfall: "Срезы никогда не вызывают IndexError при выходе за границы: s[100:200] вернёт пустую строку \"\".",
        style: "Не пиши s[0:len(s)] — достаточно s[:].",
        topics: ["strings", "l1_strings"],
        tags: ["срез", "slice", "шаг", "step", "разворот", "подстрока", "индекс"]
      }
    ]
  }
];
```

### 3.1. Описание полей карточки (`item`)
| Поле | Тип | Обязательное | Назначение |
|---|---|---|---|
| `id` | `string` | **Да** | Уникальный идентификатор карточки (snake_case, валидируется тестами). |
| `title` | `string` | **Да** | Ёмкий заголовок карточки (например: «Метод .split()»). |
| `syntax` | `string` | **Да** | Сигнатура метода или шаблон конструкции (моноширинный). |
| `desc` | `string` | **Да** | Лаконичное объяснение сути (1–2 предложения простым языком). |
| `code` | `string` | **Да** | Компактный рабочий пример с комментариями `# результат`. |
| `pitfall` | `string` | Нет | **Пограничный случай / грабли / частая ошибка** (что может пойти не так). |
| `style` | `string` | Нет | **Рекомендация PEP 8** (как писать красиво и идиоматично). |
| `topics` | `string[]`| Нет | Массив `id` тем курса, где этот синтаксис необходим для решения задач. |
| `tags` | `string[]`| **Да** | Список синонимов и ключевых слов для живого поиска. |

## 4. Матрица разделов справочника и привязки к темам курса

В справочнике закреплено **7 обязательных разделов**:

| № | Раздел (`id`) | Название | Привязанные темы курса (`topics`) | Ключевые карточки синтаксиса |
|---|---|---|---|---|
| 1 | `basics` | **Базовый синтаксис и типы** | `variables` | Типы `int`, `float`, `str`, `bool`. Ввод/вывод `print()`, `input()`, приведение `int()`, `str()`. Операторы деления `/`, `//`, `%`. f-строки. |
| 2 | `control` | **Условия и циклы** | `conditions`, `loops`, `l1_loops_adv` | `if / elif / else`. Логические `and`, `or`, `not`. Цикл `for x in iterable`. Функция `range(start, stop, step)`. Цикл `while`. Операторы `break`, `continue`. |
| 3 | `strings` | **Строки и методы** | `strings`, `l1_strings` | Срезы `s[start:stop:step]`. Методы `.split()`, `.join()`. Очистка `.strip()`. Поиск `.find()`, замена `.replace()`. Регистр `.lower()`, `.upper()`. Неизменяемость строк. |
| 4 | `lists_tuples` | **Списки и кортежи** | `lists-dicts`, `l1_lists`, `l1_tuples` | Создание `[]`, `tuple()`. Добавление `.append()`, удаление `.pop()`, поиск `.index()`. Сортировка `.sort()` vs `sorted()`. Распаковка `a, b = tup`. Неизменяемость кортежей. |
| 5 | `dicts_sets` | **Словари и множества** | `lists-dicts`, `l1_dicts`, `l1_nested_structures` | Создание `{}`. Чтение `d[k]` vs безопасный `.get(k, default)`. Перебор `.keys()`, `.values()`, `.items()`. Проверка ключа `k in d`. Уникальность в `set()`, метод `.add()`. Вложенный доступ `d[k1][k2]`. |
| 6 | `functions` | **Функции** | `functions`, `l1_functions` | Определение `def f(a, b=0):`. Оператор `return` vs `print`. Значения по умолчанию. Области видимости (LEGB, `global`). Встроенные `len()`, `sum()`, `min()`, `max()`, `abs()`. |
| 7 | `errors` | **Скорая помощь при ошибках** | *Все темы* | Разбор ошибок рантайма: `SyntaxError`, `IndentationError`, `NameError`, `IndexError`, `KeyError`, `TypeError`, `ZeroDivisionError`. |

## 6. Валидация и автотесты (`dev/run_js_validation.js`)

При добавлении справочника тестовый набор `dev/run_js_validation.js` пополняется обязательными проверками:
1. `window.CHEATSHEET_SECTIONS` экспортирован и является массивом.
2. Содержит ровно 7 обязательных разделов с корректными `id`.
3. Все `id` карточек во всём справочнике **строго уникальны**.
4. Каждая карточка содержит непустые поля `title`, `syntax`, `desc`, `code` и массив `tags`.
5. Все примеры в поле `code` синтаксически корректны (отсутствуют незакрытые кавычки и скобки).
6. Все указанные в `topics` идентификаторы соответствуют реальным темам из `COURSE_STAGES`.
