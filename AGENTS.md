# Правила для агентов вкат.py

## Редакторы Python

Каждое новое поле для ввода Python-кода, включая задания пет-проектов и песочницы, должно использовать существующие `app/highlighter.js` (`PythonHighlighter`) и `app/autocomplete.js` (`CodeIntelliSense`). Подключайте слой подсветки, окно автодополнения и номера строк по образцу редакторов курса. При программной смене кода обновляйте подсветку и номера строк; при вводе и прокрутке сохраняйте синхронизацию слоёв. Проверяйте работу автодополнения, Tab и запуска с клавиатуры, а также вид на узком экране. Не оставляйте новый редактор обычным `textarea` без этих возможностей.

Проект работает без сборки и внешних зависимостей. Перед коммитом запускайте `node dev/run_js_validation.js` и профильные тесты затронутого модуля.
