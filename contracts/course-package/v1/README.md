# Публикация учебного материала, проект v1

LINZA экспортирует ученическую версию материала. Конспект преподавателя, группа и план конкретной пары остаются в LINZA. Текст в пакете отображается как обычный текст.

Схема находится в `schema.json`. Пример `matrices.json` публикует отдельную тему. В этом случае место темы в курсе выбирается при первом импорте. Пример `oop-patterns.json` публикует модуль целиком. Порядок массива `topics` задаёт порядок тем в модуле, порядок `items` задаёт маршрут внутри темы.

## Правила для будущего импортёра

- Проверить весь пакет перед записью. Отклонить неизвестную версию формата, повтор ID тем или повтор ID шагов, в том числе между разными темами. ID шагов должны быть уникальны и относительно установленного курса.
- Сопоставлять сущности по постоянным ID. Сохранять прогресс при переименовании и перемещении шага. Для нового по смыслу упражнения автор выдаёт новый ID.
- Сравнивать редакции тем по отдельности. Одинаковая редакция с одинаковым содержимым допускает повторный импорт. При другом содержимом с той же редакцией или при попытке отката отклонить весь пакет.
- Редакция модуля описывает его заголовок и упорядоченный список ID тем. Изменение текста одной темы повышает редакцию темы. Исключение темы из маршрута модуля сохраняет её историю прохождения.
- В первой версии поддерживаются текстовая теория и Python-задание с проверкой вывода. При импорте текст теории преобразуется в безопасный текстовый блок тренажёра. Проверка вывода оценивает результат запуска. Использование класса, цикла или паттерна преподаватель оценивает отдельно.
