# вкат.py

> 🚀 **Live Demo:** [ascezis.github.io/vkat_py](https://ascezis.github.io/vkat_py/)  
> 🏷️ **Текущая версия:** `v2.3.0` · Zero-Build · Offline-first

Автономный тренажёр по Python для школ и кружков программирования. Код исполняется на настоящем CPython (Pyodide WebAssembly) прямо в браузере — без установки интерпретатора, без компиляторов и без интернета.

Изначально проект создавался для ликвидации разрыва (помочь ученику, пришедшему в группу позже остальных, быстро догнать программу). Сегодня «нагонка» оформлена в стартовый модуль, а платформа выросла в полноценный тренажёр с двумя этапами обучения:

1. **Модуль «Начало» (экспресс-вкат):** 6 базовых тем (переменные, условия, циклы, функции, списки/словари, строки) для быстрого выравнивания группы и устранения пробелов.
2. **Модуль «Основной курс»:** 9 углублённых тем (185 учебных шагов) с алгоритмической практикой, строгими ограничениями на код (AST-проверки) и автоматической валидацией решений.

**Статус:** в эксплуатации в школе, активно развивается.

> **English summary.** vkat.py is an offline, in-browser Python trainer used in a programming school. Code runs on a real CPython interpreter (Pyodide/WebAssembly) bundled in the repository, is checked automatically, and needs no internet connection. Vanilla JavaScript, no build step. Includes multi-profile support with PIN isolation for shared classroom PCs.

## Возможности

- **Настоящий Python в браузере.** Интерпретатор Pyodide (WebAssembly) встроен прямо в репозиторий: код выполняется по-настоящему, а не эмулируется.
- **Модульная программа курса (211 учебных шагов всего):**
  - **Этап «Начало» (Start, 26 шагов):** 01. Переменные · 02. Условия · 03. Циклы · 04. Функции · 05. Списки и словари · 06. Строки.
  - **Этап «Основной курс» (Core, 185 шагов):** 
    - 01. Функции (сигнатуры, return vs print, pure functions)
    - 02. Словари (методы, подсчёт частот, группировка)
    - 03. Списки (индексация, срезы, мутации)
    - 04. Кортежи (неизменяемость, распаковка)
    - 05. Строки (продолжение: срезы с шагом, регистр, форматирование)
    - 06. Циклы (продолжение: `while`, `break`, `continue`, `enumerate`, `zip`)
    - 07. Вложенные структуры данных (списки словарей, матрицы, агрегация)
    - 08. Исключения и обработка ошибок (`try/except/else/finally`, типы ошибок, `raise`)
    - 09. Чистый код и оформление (PEP 8, понятные имена, плоская структура функций, комментарии)
- **Мультипрофильная система для школьных компьютеров (`VkatStorage`):**
  - Независимые профили учеников на одном ПК с аппаратной изоляцией вкладок.
  - Защита профиля 4-значным PIN-кодом (хэширование SHA-256).
  - Экспорт и импорт прогресса через JSON-файлы (ученик может забрать прогресс на флешке или сдать учителю).
  - Быстрый гостевой вход.
- **Подсказки по коду (CodeHints)**: интерактивные карточки синтаксиса и методов языка при наведении на код в блоках теории (встроенная база конструкций Python, подсветка синтаксиса, примеры, частые ловушки и рекомендации PEP 8).
- **Разнообразные типы учебных элементов:**
  - `theory` — иллюстрированные теоретические блоки со схемами (1px технические SVG-глифы).
  - `predict` — предсказание вывода программы с запуском кода и проверкой гипотезы (20 карточек).
  - `quiz` — проверочные тесты с мгновенным разбором ошибок.
  - `code` — задачи по коду с метками сложности (`warmup`, `main`, `star`), поиском ошибок (`fix`) и автопроверкой (75 задач).
- **Ступенчатые подсказки (3 уровня)**: идея без кода, каркас с пропусками, эталонное решение.
- **Дружелюбные ошибки (FriendlyErrors)**: автоматическая расшифровка исключений (`IndentationError`, `TypeError`, `NameError`, незакрытые скобки) простым и понятным языком.
- **AST-анализ кода**: чекер проверяет не только вывод, но и структуру программы (запрет `max()` или `Counter`, требование обязательного использования `if`, `while`, `try/except` или `raise`).
- **Интеллектуальный редактор**: монохромная подсветка синтаксиса, парные скобки, автодополнение встроенных функций и ключевых слов.
- **100% Офлайн и Zero-Build.** Никаких Node.js, Webpack, npm-зависимостей или CDN в рантайме. Всё работает локально «из коробки».
- **Автоматическая самопроверка курса**: встроенный раннер тестов `dev/run_js_validation.js` (312 проверок) и `python dev/run_tests.py` (204 проверки) гарантируют 100% целостность структуры, схем, AST и корректность эталонов.

## Запуск

Требуется любой современный браузер с поддержкой WebAssembly.

**Windows:** запустите `run.bat`. Скрипт найдёт Python (Python 3.12 в стандартной папке, `py` launcher или `python` в PATH), поднимет локальный сервер на порту 8085 и откроет `http://localhost:8085`.

**macOS / Linux:**

```bash
python3 -m http.server 8085
```

Затем откройте `http://localhost:8085` в браузере.

### Зачем нужен локальный сервер
Браузеры блокируют загрузку WebAssembly при открытии страницы через `file://` из соображений безопасности. Локальный сервер нужен исключительно для раздачи статических файлов.

## Структура репозитория

```
index.html              точка входа тренажёра
run.bat                 запуск локального сервера (Windows)
app/                    ядро движка (Zero-Build Vanilla JS):
├── version.js          единый источник истины версии приложения (SemVer)
├── storage.js          система мультипрофилей VkatStorage и изоляция сессий
├── profiles.js         экран авторизации, создание профилей, PIN-коды
├── renderers.js        рендеры теории, квизов, задач и предсказаний
├── checkers.js         валидация решений учеников (code / predict / quiz)
├── checker.js          AST-анализатор и рантайм-чекер решений
├── errors.js           дружелюбные расшифровки ошибок Python
├── code-hints.js       система интерактивных подсказок синтаксиса в теории
├── autocomplete.js     интеллектуальный редактор и парные скобки
├── highlighter.js      подсветка синтаксиса Python
├── glyphs.js           монохромные технические SVG-иллюстрации тем
└── app.js              оркестратор состояния и навигации
content/                учебные этапы и темы:
├── stages.js           дерево курса и цепочки этапов
├── cheatsheet.js       встроенная база синтаксических карточек Python
├── start/              модуль 1: экспресс-вкат (темы 01..06)
└── core/               модуль 2: основной курс (темы 01..08, 11)
assets/
├── pyodide/            автономный рантайм CPython (WebAssembly)
└── fonts/              локальные шрифты (IBM Plex)
docs/                   архитектура, дизайн-система, гайды по авторингу
FEATURES/               спецификации подсистем (профили, телеметрия)
dev/                    инструменты самопроверки и тестовые раннеры
```
