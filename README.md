# вкат.py

Тренажёр по Python для учеников школы программирования. Код запускается прямо в браузере, без установки интерпретатора и без интернета.

Главная идея: помочь ученику, пришедшему в группу позже остальных, догнать программу. Он проходит темы в своём темпе, а код проверяется автоматически на настоящем Python.

**Статус:** в эксплуатации в школе, активно развивается.

> **English summary.** vkat.py is an offline, in-browser Python trainer used in a programming school. Code runs on a real CPython interpreter (Pyodide/WebAssembly) bundled in the repository, is checked automatically, and needs no internet connection. Vanilla JavaScript, no build step.

## Возможности

- **Настоящий Python в браузере.** Интерпретатор Pyodide (WebAssembly) лежит в репозитории, поэтому код выполняется по-настоящему, а не имитируется.
- **Автопроверка решений.** Код ученика запускается и проверяется на тестах.
- **Подсветка синтаксиса и автодополнение** в редакторе.
- **Полностью офлайн.** Работа не зависит от интернета: интерпретатор и шрифты хранятся локально.
- **Шесть тем:** переменные, условия, циклы, функции, списки и словари, строки.
- **Без сборки.** Чистый JavaScript, HTML и CSS: ничего не нужно компилировать.

## Запуск

Требуется браузер с поддержкой WebAssembly и установленный Python 3 (нужен только для запуска локального сервера).

**Windows:** запустите `run.bat`. Скрипт найдёт Python (Python 3.12 в стандартной папке, `py` launcher или `python` в PATH), поднимет локальный сервер на порту 8085 и откроет `http://localhost:8085`.

**macOS / Linux:**

```bash
python3 -m http.server 8085
```

Затем откройте `http://localhost:8085` в браузере.

### Зачем нужен сервер

Браузеры блокируют загрузку WebAssembly при открытии страницы через `file://`, поэтому `index.html` нужно открывать через локальный сервер. Если Python не найден, `run.bat` откроет `index.html` напрямую: на части браузеров это сработает, но при строгих политиках выполнение кода будет заблокировано, и приложение покажет предупреждение.

## Структура репозитория

```
index.html          точка входа
run.bat             запуск локального сервера (Windows)
app/                логика: редактор, подсветка, автодополнение, проверка кода
content/            учебные темы, по одному файлу на тему
assets/
├── pyodide/        интерпретатор Python (WebAssembly)
└── fonts/          шрифты
docs/               архитектура, дизайн-система, макеты экранов
```
