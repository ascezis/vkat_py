# Инструкция для Claude: Разработка контента и тем в вкат.py

> **Как использовать эту папку:**  
> Передайте Claude этот файл (`00-INSTRUCTIONS-FOR-CLAUDE.md`) вместе с файлами спецификаций из папки `CLAUDE/`.  
> Достаточно сказать: *"Напиши тему X согласно спецификациям в файлах"*.

---

## 1. О проекте «вкат.py»
**вкат.py** — это полностью автономный (Zero-Build, офлайн, без npm/Webpack) тренажёр по программированию на Python для школьников и начинающих.
- **Рантайм:** CPython в браузере через Pyodide WebAssembly.
- **Дизайн:** Строгий минималистичный монохром (черно-белая палитра, терминальная эстетика, без скруглений и теней, акценты только через подсветку кода).
- **Тон текста:** Дружелюбный наставник на «ты», без сухой академичности и без сюсюканья. Объяснения через живые аналогии и короткий понятный код.

---

## 2. Архитектура контента
Каждая тема курса оформляется в виде **одного независимого JavaScript-файла** в директории `content/`:
```text
content/
  stages.js              ← реестр этапов курса (start, core)
  start/                 ← вводные темы (01-06)
  core/                  ← темы основного курса (01-08)
    01-functions.js
    02-dicts.js
    ...
  cheatsheet.js          ← база справочника и подсказок по синтаксису (CodeHints)
```

Каждый файл темы добавляет объект темы в глобальный массив:
```javascript
window.COURSE_TOPICS = window.COURSE_TOPICS || [];
window.COURSE_TOPICS.push({
  id: "l1_topic_id",
  title: "Название темы",
  items: [ /* учебные шаги: theory, quiz, predict, fix, code */ ]
});
```

---

## 3. Что нужно знать про подсказки по коду (Code Hints)
В проекте работает система всплывающих контекстных подсказок (`CodeHints`):
- Когда ученик читает теорию (`type: "theory"`), слова в блоках кода (`.theory-block-code`) автоматически распознаются и подчёркиваются пунктиром.
- При наведении или клике всплывает карточка с синтаксисом, описанием, примером и ловушкой (pitfall).
- **Если тема использует стандартные конструкции** (`def`, `return`, `for`, `in`, `range`, `len`, `int`, `.get()`, `.append()`, `dict`, `list` и т.д.) — **писать хинты НЕ нужно**, система подключит их сама!
- **Если тема вводит НОВУЮ синтаксическую конструкцию** (например, `try/except/finally/raise`, `import`, `with/open`, `class/self/__init__`) — автор темы добавляет карточки в `content/cheatsheet.js` по спецификации `02-HINTS-SPEC.md`.

## 5. Чеклист сдачи темы от Claude
При разработке новой темы Claude должен предоставить:
1. Полный JavaScript-код файла `content/core/NN-topic-name.js`.
2. Правку в `content/stages.js` (добавление `id` темы в массив `topics`).
3. Правку в `index.html` (подключение `<script src="content/core/NN-topic-name.js"></script>`).
4. Если введены новые синтаксические конструкции — фрагмент карточек для `content/cheatsheet.js`.
5. Эталонные решения и негативные тесты (wrong solutions) для добавления в `dev/run_tests.py`.
