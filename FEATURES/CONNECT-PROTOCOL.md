# Connect Protocol — Спецификация протокола телеметрии и мониторинга

Документ описывает архитектуру легковесного, провайдер-агностичного протокола синхронизации и сбора телеметрии прогресса учеников.

---

## 1. Цели и принципы

- **Провайдер-агностик (Zero-Vendor Lock-in):** Тренажёр не зависит от конкретного сервиса, базы данных или облака. На стороне клиента используется только стандартный браузерный `fetch()`.
- **Автономность и надёжность:** Работает даже при строгих сетевых политиках и блокировках (без сторонних мессенджеров вроде Telegram). Поддерживает доверенные домены (Яндекс, локальная сеть).
- **Качественный снимок работы (а не просто галочки):** Фиксирует не только факт завершения задачи, но и то, *как* ученик её решал: количество попыток, с какими ошибками он сталкивался, сколько времени провёл над задачей и какой финальный код написал.
- **Отказоустойчивость (Outbox Pattern):** При сбоях сети отчёты буферизуются в `localStorage` и автоматически досылаются при восстановлении соединения.

---

## 2. Спецификация пейлоада (`vkat-connect/v1`)

При завершении темы, этапа или по явному нажатию «Сдать работу» клиент формирует снимок следующей структуры:

```typescript
interface ConnectSnapshot {
  protocol: "vkat-connect/v1";
  timestamp: number;                   // Unix timestamp отправки
  student: {
    profileId: string;                 // Уникальный ID профиля (например "k9f2x7a1")
    name: string;                      // Имя ученика
  };
  session: {
    stageId: string;                   // ID этапа ("start", "core", ...)
    topicId: string;                   // ID темы ("l1_functions", ...)
    timeSpentSeconds: number;          // Общее время работы в секундах
  };
  summary: {
    totalItems: number;                // Всего шагов в теме
    completedItems: number;            // Успешно закрыто шагов
    totalAttempts: number;             // Суммарное количество нажатий "Проверить"
  };
  solutions: Array<{
    itemId: string;                    // ID задания (например "l1_fn_c1")
    type: "code" | "predict" | "quiz"; // Тип задания
    passed: boolean;                   // Решено ли успешно
    attempts: number;                  // Количество попыток
    errorsEncountered: string[];       // Список классов ошибок (IndentationError, NameError и т.п.)
    finalCode?: string;                // Итоговый код в редакторе (для code)
    userAnswer?: string;               // Ответ ученика (для predict / quiz)
  }>;
}
```

## 3. Транспортный контракт

Клиент тренажёра настраивается через единственный параметр конечной точки:

```javascript
window.VKAT_CONNECT_ENDPOINT = "https://..."; // URL приёмника
```

- **Метод:** `POST`
- **Заголовки:** `Content-Type: application/json`
- **Тело:** сериализованный объект `ConnectSnapshot`

### Буферизация при отсутствии сети (Outbox)
1. Если `fetch()` завершается сетевой ошибкой или таймаутом, снимок помещается в локальную очередь: `localStorage.getItem('vkat_outbox')`.
2. При следующем успешном подключении или старте приложения очередь автоматически вычитывается и досылает накопленные снимки.

## 4. Поддерживаемые типы приёмников (Sinks)

Благодаря стандартному JSON-формату учитель может настроить любой удобный приёмник без изменения кода тренажёра:

### Вариант А: Яндекс (Рекомендуется для школ РФ)
- **Яндекс Cloud Functions:** Бесплатная бессерверная функция на 15 строк кода (до 1 млн вызовов в месяц бесплатно). Принимает JSON и складывает в Yandex DataLens, Tracker или таблицу Яндекс 360.
- **Плюсы:** Яндекс входит в «белые списки» Минпросвещения РФ, никогда не блокируется школьными DPI/РКН, разрешён на экзаменационных и учебных компьютерах.

### Вариант Б: Локальный кабинетный сервер (`teacher.py`)
- **Как работает:** Учитель на своём ноутбуке запускает скрипт из 25 строк на стандартной библиотеке Python (`http.server`).
- **Плюсы:** Работает **на 100% без интернета** в школьной локальной сети по Wi-Fi или витой паре. Ученики шлют снимки на локальный IP преподавателя (`http://192.168.1.100:8000/report`). У преподавателя открыт живой монитор класса.

### Вариант В: Google Apps Script / Google Sheets
- **Как работает:** Вебхук в Google Таблицах, дописывающий строчку по каждому ученику.
- **Плюсы:** Удобно для репетиторов и онлайн-кружков с доступом к Google-сервисам.
