## Часть 1. Функция: определение и вызов

Функция — это поименованный блок кода, который можно вызывать многократно из разных мест программы.

### Объявление функции
Функция объявляется ключевым словом `def` (от английского *define* — определить):

```python
def say_hello():
    print("Привет!")
```

### Главное правило
**Строка с `def` только создаёт и запоминает функцию. Код внутри неё НЕ выполняется, пока функция не будет вызвана.**

```python
def greet():
    print("Привет из функции!")

# Программа дошла сюда, но на экране пока пусто.
# Чтобы запустить код функции, её нужно вызвать:
greet()  # Напечатает: Привет из функции!
```

## Часть 2. Параметры и аргументы

Функции становятся по-настоящему полезными, когда они умеют работать с разными данными.

### Параметры vs Аргументы
- **Параметр** — это имя переменной в скобках при объявлении функции (`def`).
- **Аргумент** — это конкретное значение, которое передаётся в функцию в момент её вызова.

```python
def welcome(name):       # name — параметр
    print("Привет,", name)

welcome("Алиса")         # "Алиса" — аргумент
welcome("Боб")           # "Боб" — аргумент
```

### Порядок аргументов и именованные аргументы
По умолчанию аргументы передаются по порядку (позиционные):
```python
def show_rect(w, h):
    print(f"Прямоугольник {w} на {h}")

show_rect(10, 5)  # w=10, h=5
```

Можно явно указывать имена параметров при вызове (именованные аргументы):
```python
show_rect(h=5, w=10)  # порядок не важен
```

### Несовпадение количества аргументов
Если передать меньше или больше аргументов, чем указано параметров в `def`, Python выбросит ошибку `TypeError`:
```python
show_rect(10)        # TypeError: missing 1 required positional argument: 'h'
show_rect(10, 5, 2)  # TypeError: takes 2 positional arguments but 3 were given
```

## Часть 3. return и print

Это одно из главных понятий программирования, в котором новички чаще всего ошибаются.

### Разница между print и return
- `print(...)` — это команда для **человека за экраном**. Она выводит символы в окно консоли и «забывает» их. Программа не может сложить или сохранить вывод `print`.
- `return ...` — это команда для **программы**. Она возвращает вычисленное значение обратно в место вызова функции, чтобы его можно было сохранить в переменную, передать в другую функцию или использовать в выражениях.

```python
def add(a, b):
    return a + b

total = add(3, 5) * 2  # add(3, 5) вернула 8, умножаем на 2 -> 16
print(total)           # 16
```

### Что возвращает функция без return?
Если в функции нет `return` (или написан пустой `return`), функция возвращает специальное значение `None` («ничего»):

```python
def bad_double(x):
    print(x * 2)

res = bad_double(5)    # Напечатает 10
print(res)             # Напечатает None!
# res + 5 вызовет TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'
```

### Ранний выход из функции
Инструкция `return` немедленно завершает выполнение функции. Любой код после `return` игнорируется:

```python
def check_age(age):
    if age < 18:
        return "Доступ закрыт"
    return "Добро пожаловать"
    print("Этот код никогда не выполнится")
```

## Часть 4. Значения по умолчанию и локальные переменные

### Значения по умолчанию (default arguments)
Параметрам можно задавать значения по умолчанию. Если аргумент не передан при вызове, используется это значение:

```python
def rectangle(w, h, symbol="#"):
    for _ in range(h):
        print(symbol * w)

rectangle(4, 2)       # Использует symbol="#"
rectangle(4, 2, "@")  # Использует symbol="@"
```
*Важно:* параметры со значениями по умолчанию всегда должны идти **после** обязательных параметров.

### Локальные переменные и область видимости (scope)
Переменные, созданные внутри функции, называются **локальными**. Они существуют только во время работы функции и снаружи функции **не видны**:

```python
def calculate():
    result = 42

calculate()
print(result)  # NameError: name 'result' is not defined!
```

Чтобы передать значение из функции наружу, всегда используй `return`:
```python
def calculate():
    result = 42
    return result

value = calculate()
print(value)  # 42
```

## Часть 5. Таблица частых ошибок

| Ошибка / Ситуация | Причина | Как исправить |
|---|---|---|
| `IndentationError: expected an indented block` | Внутри `def` нет отступа в 4 пробела | Добавь отступ 4 пробела ко всем строкам тела функции |
| `SyntaxError: expected ':'` | Забыто двоеточие в конце строки `def` | Поставь `:` в конце строки заголовка функции |
| `TypeError: unsupported operand for +: 'NoneType' and 'int'` | Функция вместо `return` сделала `print`, вернулся `None` | Замени `print` внутри функции на `return` |
| `NameError: name 'my_func' is not defined` | Вызов функции написан до её объявления или опечатка в имени | Объяви функцию выше по тексту или проверь регистр и буквы |
| `TypeError: missing 1 required positional argument` | В `def` объявлено больше параметров, чем передано в вызове | Передай все обязательные аргументы при вызове функции |
| Функция не запускается (вывод пуст) | Функция объявлена через `def`, но нигде не вызвана | Добавь строчку с вызовом функции `my_func()` |
